# 纯游客版本发布前检查

日期：2026-10-25。仓库：`kden3995-max/qingying-plan`。网站：<https://kden3995-max.github.io/qingying-plan/>。

用户授权只发布第一阶段内存游客模式，暂不接入登录和云端保存。第二阶段文档仅为方案，不会加载到网页，也没有可点击的假登录入口。本文件记录发布准备和回退点；实际发布状态以本次 GitHub 提交、Pages 工作流及线上验收为准。

## 隐私说明与实际行为

- 已按最新要求移除全站顶部游客横幅。首页首次进入仅显示一行：“无需登录即可使用，刷新后资料会清空”；站内返回不重复。记录及备份工具附近提示刷新／退出前导出，详细隐私说明可展开查看。结束入口位于页脚、手机菜单和记录工具区，不遮挡填写或计划结果。
- 资料、体重、打卡、感受与草稿仅在 JavaScript 内存中保留。UI 不调用旧版自动存储工具，不自动写 localStorage、sessionStorage、Cookie 或云端，没有身份认证 SDK、分析追踪或云端请求。
- 刷新、重新进入、跨文档离开、结束体验、页面缓存恢复会清空可控制的页面状态；站内返回修改属于同次体验，保留内存资料。结束后历史返回不能复活上一体验。
- 旧版 `qingying-state-v1` 默认仅检查键是否存在，确认属于自己后才读取并恢复到本次内存。旧副本需另行明确删除，不随结束体验偷偷移除。
- 手动备份会下载含健康信息的文件。结束体验不会删除已下载文件、系统截图或旧版副本；网页对此作出明确说明，不声称设备级安全擦除。
- `app.js` 与 `features.js` 相对此前发布文件树逐字节不变，保留计算规则、健康限制与备份校验。
