# UI 改版检查记录

验证日期：2026-10-24。分支：`feature/apple-bento-spa`。基线：`08a383e`。本轮仅本地实现，未推送、未合并、未部署。

## 改动

- 浅灰背景、白色／浅绿 Bento 卡片、深绿操作色、系统字体和本地统一线性图标。
- 首页、三步资料填写、计划结果独立显示；结果分为总览、饮食与运动、记录回顾。
- Hash 路由支持按钮切换、浏览器前进后退、回到顶部和标题焦点。表单保持挂载，切换保留未提交内容，刷新恢复已保存资料。
- 结果依据提交时的资料；草稿变更时明确提示待重新生成。示例需主动打开，且不写入个人资料；没有计划／记录时显示空状态。
- 核心目标数字突出；BMI 与活动简短指标使用小卡片，完整说明放在全宽区域。手机日期按钮可换行；图表坐标按容器尺寸绘制，避免文字缩小。
- 存储故障／冲突提示在所有界面可见；保留原有导入确认、清空确认和数据保护。

## 审查与修正

一次独立代码审查提出两项 P2：原先允许的小数精度被原生 step 校验收窄、健康条件未填写时过早执行完整目标校验。两项均先在浏览器复现失败，再修正并增加回归覆盖；原审查者复核确认已解决，无剩余阻断项。

视觉比较修正了手机核心卡片高度与数字层级、过小的日期触控按钮、手机图表坐标字号。详细前后对照见 `design-qa.md`。

## 验证边界

实际渲染与交互验证使用此环境的 Chromium／Playwright，覆盖手机视口与桌面视口；未使用 iPhone 真机、Safari／VoiceOver 或其他浏览器。因此不声称已完成真机兼容性认证。没有测试或触发线上 Pages 发布；线上网站不包含本轮改版。

## 本地复查

运行 `npm run dev` 后打开 `http://127.0.0.1:4173/#/home`。核心路径：首页 → 开始填写 → 三步填写 → 生成 → 总览／一周／记录；修改资料后先看待更新提示，再提交重新生成。数据仅保存在所用浏览器的该站点存储中。
